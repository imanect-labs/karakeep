# 本文翻訳をボタンから実行する

- 保存・クロール時の自動翻訳を本番で無効にし，リーダーの全文翻訳ボタンから開始する。
- 所有者を確認して本文のあるリンクだけを受け付ける。二重要求を抑止し，失敗時は再試行可能。
- キューは requestedByUser を記録し，自動実行を止めても手動の翻訳を処理する。
- 古い自動ジョブは推論を呼ばずにスキップし，success と誤記録しない。
- 既存の翻訳，部分翻訳の再開，原文と日本語の切り替えは維持する。
- 本番の TRANSLATION_ENABLE_AUTO=false は，新イメージの反映時に設定する。
- 確認: 所有者境界，二重要求，本文未取得，キュー投入失敗，自動ジョブのスキップと手動実行をテストする。
