# 推薦の表示順とペアワイズ学習

- 作業日時: 2026-11-08
- 問題: trial → uncertain → random → adjacent → exploit の抽出順がそのまま表示順位になり、10 件ずつのページ送りでは関心に近い記事が後ろに回る。`train` ジョブは未実装だった。
- 変更: 探索席の確保・多様性制約・抽出確率は保ち、選んだ記事をスコア順で表示する。
- 学習: 既存の `heuristic-v1` 特徴量スナップショットを使った L2 正則化ペアワイズ回帰。bootstrap・未提示・未観測・未到達・報酬未確定・不完全な特徴量は対象外。同一 Briefing の相対比較だけを生成する。rank は学習時のみ使い、推論・評価では 1 固定。
- シャドー学習開始: examined 100、異なる記事の強い正例 20、観測日 5、ペア 100。以前の 2,000 / 100 / 60 / 3,000 は学習開始には慎重すぎるというユーザー判断で変更。時系列 CV が可能なら正則化を選び、短い履歴では事前に決めた強い L2 正則化 (lambda=1) を使う。自動昇格は行わない。
- モデル: `recModels.status=shadow` で保存し、次の rank から最古の未評価 shadow モデルの予測を `recImpressions.features["shadow:<version>"]` に記録する。既存の特徴量・選定理由・提示モデルは変えない。DB マイグレーション不要。
- 検証: recommender の全ユニットテスト、recommender/workers の型・lint チェック、workers のテスト。

## 本番確認と残作業

SSH 認証後に本番 DB を確認。確定済み examined 437、異なる記事の強い正例 69、観測日 15、比較ペア 3,736。候補収集と埋め込みは正常だった。現在のデプロイは別リポジトリ `giken-ops` の image tag で固定されており、この変更のマージだけでは本番反映されない。

この変更は Phase 2 の学習と予測記録を開始するもの。自動昇格・学習済みモデルによる実提示はまだ実装していない。7 日以上の将来データと報酬確定を待ち、固定したモデルバージョンについてペア正解率・NDCG@20・上位保存率を比較する。過去の検証指標だけで昇格しない。

ロールバックは giken-ops の web image tag を直前の SHA に戻す。モデル行は shadow のままなので、学習ジョブだけを止めても提示は heuristic-v1 のまま継続する。

評価中のモデルを固定するため、rank は最古の未評価 shadow を使う。日次再学習モデルは保存するが、評価中の予測器を日替わりにはしない。評価後、該当バージョンを retired にするまで同じモデルの予測記録を続ける。

## 本番で確認したプロフィール同期漏れと復旧

- 初回 enroll 以降、通常の保存記事を bootstrap していなかった。9月以降の保存83件がプロフィール候補に無く、recentEmbedding は null になっていた。
- maintain から冪等な bootstrap を毎日呼ぶ。候補プールと同じ URL の手動保存は、URL 一意制約で無視せず既存候補をライブラリへ紐付ける。既に表示済みでも saved 未記録なら bootstrap の正例を作る。
- read_intent により既に bookmarkId が付いている collected 候補は対象外とし、「読む」を保存の正例に変えない。再実行しても正例を重複作成しないことを、実 SQLite のマイグレーションを使ったテストで確認。
- 本番では既存 bootstrap ジョブから107件を取り込み・埋め込み。URL 衝突の修正でさらに30候補をライブラリへ紐付け、プロフィールを再構築して recentEmbedding の復旧を確認。
- 本番 DB の整合したバックアップを `/data/db.before-recommender-shadow-20261108.db` に保存後、変更した train 処理を一時スクリプトとして実行。モデル `logreg-v1-d6fcdbc6-109d-4dc0-9a8f-43efe0af67a5` を shadow で保存。過去の直近 holdout には比較ペアが無いため、検証スコア0を精度の測定値と解釈してはいけない。validationPairs / validationBriefings も記録する。
- 一時実行ファイルは処理後に削除。常駐ワーカーはまだ旧イメージなので、毎日の同期・学習・予測記録を継続させるには image tag 更新が必要。

本日分は openedAt が無くフィードバックも0件であることを確認して再生成。50件がスコア順になり、全件に recent の寄与と固定 shadow モデルの予測が入ることを確認。既存の反応がある Briefing は再生成していない。
